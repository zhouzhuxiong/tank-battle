# 坦克大战 - Tank Battle

经典 FC 坦克大战的 HTML5 网页版实现，纯前端、无需安装，浏览器打开即玩。

## 🎮 游戏截图

![screenshot](screenshot.png)

## 🕹️ 操作方式

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → / WASD | 移动坦克 |
| 空格 / J | 发射子弹 |
| P | 暂停/继续 |

## ✨ 游戏特性

- 🎯 经典坦克大战玩法 — 保护基地，消灭所有敌方坦克
- 🧱 可破坏砖墙 & 不可破坏钢铁墙
- 🌊 水域地形（不可通行）
- 🧪 道具系统：
  - ⭐ 星 — 升级坦克（速度↑ → 双发）
  - 🛡 盾 — 无敌状态
  - 💣 炸弹 — 清除场上所有敌人
- 📈 关卡递增 — 敌人数量递增、AI 变强，3 关后程序化生成新地图
- 🔊 Web Audio API 音效
- ❤️ 生命系统 — 最多 5 条命

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/YOUR_USERNAME/tank-battle.git

# 直接用浏览器打开 index.html
cd tank-battle
open index.html
```

或者直接双击 `index.html` 在浏览器中打开即可。

## 🛠️ 技术栈

- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- Web Audio API
